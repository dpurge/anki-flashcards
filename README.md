# Anki flashcards

## Build

```sh
uv run anki-build --help
uv run anki-build build ./dat/lang-vocabulary/cmn-hans/flashcard.yml -o ./out/chinese-simplified.apkg
uv run anki-build build ./dat/lang-vocabulary/deu/flashcard.yml -o ./out/german.apkg
uv run anki-build build ./dat/lang-vocabulary/tur/flashcard.yml -o ./out/turkish.apkg
uv run anki-build build ./dat/lang-vocabulary/vie/flashcard.yml -o ./out/vietnamese.apkg
```
